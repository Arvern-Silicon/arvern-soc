# demo_effects — classic demo effects on Belenos

Five classic demo effects on the LT24 panel, one after the other, in a loop. Each one
leans on a different part of the aRVern core and the Belenos graphic controller. The
display is 320 × 240 at 8 bpp, with two frames back to back in the VRAM (F0, F1).

| LEDs | Effect | How it is made |
|---|---|---|
| 1 | **Starfield** — a flight through 360 stars, cruise, warp with motion streaks, cruise | perspective projection on the CPU; each frame drawn in the back buffer (one clear, then GPU fills per star; streaks: two GPU lines one row apart, `blns_gpu_line_px`, which replace the CPU's Bresenham walk cut into one fill per row run) and flipped at the next refresh |
| 2 | **Plasma** — flowing colours | a sum-of-sines pattern over both frames, computed once (four pixels per 32-bit VRAM write); then only the palette is rewritten each frame (colour cycling, double-buffered LUT) and the refresh frame pointer bobs over the taller pattern |
| 3 | **Torus** — a flat-shaded torus flies in and tumbles, aRVern logo panels on it | 128 quads rotated (Q14 matrix), culled, depth-sorted and lit on the CPU; each face filled as a convex quad, one one-word GPU span (`EXEC_SPAN`) per row; each scanline of a logo panel is one textured span (`EXEC_TEXSPAN`, affine, the logo texture in the VRAM); drawn into the hidden frame, then a frame-pointer flip |
| 4 | **Fire** — the ground burns around the aRVern logo (the 2001 Demo_fire), the fields burn out and the volcano erupts | a 160 × 54 heat map in RAM (2 × 2 pixels a cell), each row computed only over the span the heat can reach; each row written once at double width, then one GPU copy with a 640-pixel pitch doubles every line; the logo (painted once off screen in F1) copied over it with a transparent colour, its palette flickering with the fire; the burning ground, before the eruption, is the 2001 fire rule computed four pixels a word (`fx_fire_asm.S`) in a 64-line band, copied in by the GPU under the logo |
| 5 | **Sine scroller** — a message waving over copper bars | every screen row has its own palette entry, so the moving bars are pure LUT animation; the text is drawn column by column, each at its own height, with a drop shadow: one GPU `EXEC_EXPAND` per column from the font kept in the VRAM; double-buffered |

**KEY[1]** skips to the next effect; **SW[0]** holds the current one. The scroller lasts
until its whole message has gone by; change the message in `fx_scroll.c` (capitals,
digits and `!'+,-./:?` only).

## Layout

| File | Contents |
|---|---|
| `main.c` | the effect list |
| `fx.h`, `fx_common.c` | sine table (Q14), random numbers, line drawing, the shared working memory (`fx_mem()`), `fx_clear()` |
| `fx_stars.c`, `fx_plasma.c`, `fx_torus.c`, `fx_fire.c`, `fx_scroll.c` | one effect each (`fx_fire_asm.S`: the burning ground's line kernel) |
| `font_data.h` | the scroller font, generated by `tools/font2c.py` (IBM Plex Sans Bold, see `THIRD_PARTY.md`); `make font` regenerates it |

The panel set-up, the double-buffered palette, timing and the effect loop come from the
shared [`../../lib/demo_kit`](../../lib/demo_kit/demo_kit.h); the logo tables of the fire
from [`../demo_arvern_logo`](../demo_arvern_logo/README.md).

## Build and run

```
make            # demo_effects.elf / .ihex
make run        # load over the JTAG DTM (see the Makefile for UART / I2C)
```

or build it into a bitstream: `synthesis/altera/0_create_bitstream.sh demo_effects`.

The board-level simulation builds the firmware with `-DSIMULATION` (every effect cut to a
few frames, faster motion, one pass, then the LEDs show `0xA5`) and saves the panel image
after every frame as `frame_log/fb_<n>.png`. It takes about 15 minutes under Verilator:

```
cd ../../../sim/rtl_sim/run
SIMULATION_DEFINES="-D NO_TIMEOUT" ./run demo_effects -nodump
```
